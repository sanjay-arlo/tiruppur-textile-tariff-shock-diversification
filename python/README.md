# Optional Python Layer

Baseline workflow: **Excel → SQL → Power BI → Decision**.

Use Pandas + NumPy for EDA, concentration analysis, sensitivity testing, segmentation or automation when it adds value.

Suggested use here:
- Pandas: monthly market/product profiling and order-book transformations.
- NumPy: concentration thresholds, tariff-shock sensitivity and numerical checks.

Python is optional; SQL and Power BI remain the governed analytical layers.
