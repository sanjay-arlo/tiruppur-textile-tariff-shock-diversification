# Tiruppur Textile Export Tariff-Shock & Market Diversification

> **Business Analyst / Data Analyst portfolio case study** analysing export-market concentration, tariff-shock exposure, margin pressure and diversification scenarios for Tiruppur knitwear businesses.

## 🚀 Live Dashboard

**[Open the interactive dashboard](https://sanjay-arlo.github.io/tiruppur-textile-tariff-shock-diversification/)**

## Executive summary

This case converts export-order data into a commercial decision workflow: reconcile order and margin measures, quantify tariff exposure, segment market concentration, test diversification scenarios, visualise revenue-at-risk, and recommend where management should diversify.

## Business problem

**How exposed is the export order book to tariff shocks and market concentration, and which alternative markets/products offer the best risk-adjusted opportunity?**

## Analyst workflow

**Excel → Python / Pandas / NumPy (optional) → SQL / MySQL → Power BI → Decision**

### 1. Excel — first-pass control

Clean monthly orders, standardise market/product fields, calculate margin and tariff exposure, build pivots and identify concentration outliers and exception markets.

### 2. Python — optional analytical layer

Use **Pandas + NumPy** for exploratory market concentration analysis, scenario transformations, distribution/outlier checks and repeatable sensitivity calculations.

### 3. SQL / MySQL — mandatory analytical layer

Use joins, CTEs, aggregations, window functions, market/product segmentation, ranking and exception queues to quantify order value, margin risk and diversification gaps.

### 4. Power BI — mandatory executive layer

Build governed measures and an executive story: **Export Executive → Market Mix → Tariff & Margin → Diversification Scenario**, with drill-through and commercial slicers.

### 5. Decision — mandatory outcome

Recommend target markets/products using **priority, owner, action, revenue impact, margin trade-off and scenario assumptions**.

## KPI framework

- **Market concentration %** = revenue from top market / total export revenue × 100
- **Revenue-at-risk** = exposed revenue × scenario order-loss rate
- **Export margin %** = portfolio margin indicator from the source data
- **Diversification opportunity** = alternative-market value potential relative to concentration reduction and margin trade-off

## Important limitation
